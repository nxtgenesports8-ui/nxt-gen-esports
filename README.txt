# NXT GEN ESPORTS SCRIMS — Website v2

Included:
- Your supplied poster as `poster.png`
- Poster is clickable and scrolls directly to registration
- Registration fields: team name, contact number, slot timing, number of slots, price category
- WhatsApp registration message to the configured NXT GEN contact
- Timings: 1–3 PM, 3–5 PM, 5–7 PM, 7–9 PM, 9–11 PM, 11 PM–1 AM
- 18-team limit per timing
- Slot availability display
- Local owner test controls: +1, -1, sold out, reopen, pause all, resume all

IMPORTANT:
GitHub Pages is a static hosting service. A genuinely private owner/partner dashboard with shared live data and separate logins cannot be made secure with only HTML/CSS/JS/localStorage. The included control panel is a prototype stored only in the browser.

For the final owner + partner system, the next version should connect the site to a real backend/database and authentication. That is also where registrations can be stored centrally and both authorized accounts can see the same data.

The current version deliberately does NOT try to verify payments automatically.
